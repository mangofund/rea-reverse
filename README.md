# rea-reverse

供 REA 等执行型 Agent 使用的逆向分析 Skill。

对软件、Web 服务、App、文件格式或协议做授权范围内的逆向：确认授权、按目标类型选择方法、收集证据、建立并验证假设，产出带证据的分析报告，必要时给出 clean-room 复现。不用于破解、绕过付费或保护、提取凭据，也不用于编写恶意软件。

## 内容

- `SKILL.md`：技能正文（授权确认 → 环境探测 → 目标分类选方法 → 证据收集 → 假设建模与验证 → 可选 clean-room 复现 → 交付与验收清单）
- `skill.yaml`：技能元数据

## 交付物结构

每次分析产出一个独立目录：

- `00-scope.md`：授权与范围
- `01-env.md`：环境探测
- `02-evidence/`：原始证据
- `03-hypotheses.md`：假设与验证状态
- `REPORT.md`：结论摘要 → 架构与数据流 → 关键机制 → 已证实 / 推测 / 未知 → 局限与未做的事 → 证据索引
